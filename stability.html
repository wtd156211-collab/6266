三种算法的误差比

误差比 = |算法值 − 高精度参考值| ÷ (1e-9 + 1e-9×|参考值|)；柱高按 log10(误差比 + 1) 映射以便同图对比，柱顶标注为误差比精确值；红色虚线为容差线（误差比 = 1）， 柱高不超过容差线即该项进容差。参考值由 decimal 60 位有效数字在同一遍输入中顺带算出。

口径说明

  • 分桶：x>0 时取整数 e 使 10^e ≤ x < 10^(e+1)，首位 d = ⌊x / 10^e⌋，桶记作 (+e, d)； x<0 对 |x| 同样分桶记作 (−e, d)；0 单独一桶。每个桶只维护个数与总和。
  • 分位数：桶代表值 = 桶内元素算术平均；rank r = p×(n−1)，i = ⌊r⌋，f = r−i， 按第 i / i+1 个元素（升序、0 基）所在桶的代表值线性插值，最后夹到 [min, max]。
  • stable：均值用 Neumaier 补偿求和，总体方差用 Welford 递推并对 M2 补偿累加（除以 n）。
  • naive：float 直接累加 Σx、Σx²；shifted：以第一个数为平移量累加后换算。
  • 容差：|得到值 − 精确值| ≤ 1e-9 + 1e-9×|精确值|；误差比即左端除以右端。
