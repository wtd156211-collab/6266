# 现场记录：同一份数据两个报表对不上

（从值班群和交接记录里摘的，上面的数字都是当时报出来的原值）

- 08-19 值班报表和监控报表拿同一份 1000 个数的批次算方差，就是
  `samples/data/02-big-small-step.txt` 那份（1000000000 起步、步长 0.5）：
  一个报 20864.0，一个报 20833.3125，差 30 还多。另一批数更大（1e12 那一档）的时候，
  值班报表的方差直接出过负数，被当成采集异常挂起来了。
- 08-20 结算侧说均值也不稳：`samples/data/01-spread-sign.txt` 那份（1e16 与 -1e16 混排），
  两边一边报 0.12500000016666665、一边报 -0.0416666665，连正负号都不一样；
  量级大的那几行谁先谁后都能把结果带跑。
- 08-22 抽样比过分位数，`samples/data/07-scale-1e7.txt` 那份 1000 万行的数据：
  一边按「桶里取平均再插值」报 p50 = 4.5，另一边按「取第 k 个元素」报 4，
  还有一边直接拿桶的中点报了个偏大的数。口径不一样就比不了，最后决定桶怎么切、
  桶里怎么取代表值、怎么插值，全部写死在 README 里。
- 08-25 交接时补了一句：均值、方差这类指标，落在小数位上的差异就足够让两个报表对不上，
  验收要看跟精确值的偏差，不要只看两边是不是「看起来差不多」。
